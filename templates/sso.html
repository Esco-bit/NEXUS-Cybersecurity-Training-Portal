Google SSO

Single Sign-On allows users to access approved applications using an identity provider.

Simulation only

This is an educational demonstration. No Google account authentication takes place. Never enter Google credentials on this page.

How SSO works

1. The application redirects the user to an identity provider.

2. The identity provider authenticates the user.

3. An approved authentication response is returned.

4. The application validates the response before granting access.
